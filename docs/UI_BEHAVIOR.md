# UI Behavior

## Quiz

The quiz is mobile-first at a 390×844 reference viewport. It collects identity and separate consent before the quiz, presents neutral answers with randomized order where enabled, uses an analyzing transition, then reveals result identity, detail, sharing, and mission completion. Retry and result visibility follow quiz configuration.

## Live monitor

At 1920×1080, rotate exactly four main slides: overall, DKV, MPLB, and PM. Retain a fixed right sidebar on every slide with QR and compact activity feed. Poll lightweight statistics and latest activity endpoints. New entries animate upward from the bottom; oldest leaves at top; newest may briefly highlight. Example entry: “Halo, Anggita Pratiwi. Anda Cocok di Jurusan DKV.” It is a compact entry, never a full-screen popup.

## Admin

Desktop-first screens allow non-technical staff to manage school profile, appearance, programs, quizzes, questions, campaigns, QR/links, participants, results, analytics, monitor settings, and settings without source edits.
