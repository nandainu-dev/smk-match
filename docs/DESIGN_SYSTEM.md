# Design System

The visual language is playful and game-like: cream/off-white base, dark-purple outlines, lime/pink/cyan accents, bold playful type, thick rounded borders, and sticker/doodle/game-show motifs. The dashboard uses the same character while remaining calmer and functional.

Program identity is primarily for result and showcase states: DKV uses purple/magenta/cyan; MPLB blue/teal/mint; PM orange/yellow/coral. These identities must not leak into quiz answer choices or imply scoring direction. Exact tokens, typography assets, component specifications, and accessibility contrast checks are TODO for the design-import and implementation gates.

Supplied visual references may show school-specific sample branding. They are design examples, not fixed application identity; all school branding remains configurable.
