# Deployment Specification

Target environment: shared hosting, planned for Hostinger, with PHP 8.x and MySQL/MariaDB as intended technologies. No production connection or deployment is authorized in this baseline.

## Pending hosting verification

The following are **PENDING VERIFICATION** and must not be assumed available: exact PHP version; exact MySQL/MariaDB version; SSH; Git deployment; Composer; cron jobs; web-server/rewrite details.

Before launch, verify capabilities, provision environment configuration securely, configure HTTPS, validate backup and rollback, run deployment/UAT procedures, and obtain explicit production authorization. No automatic production deployment is permitted.
